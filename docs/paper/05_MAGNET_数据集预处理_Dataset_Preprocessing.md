# 数据集与预处理

我们在 SWE-bench Multimodal 和 OmniGIRL 上开展实验。为统一两个数据集的输入格式、降低不受控外部链接带来的安全风险并防止 gold 信息泄漏，我们对问题描述、仓库信息、图像和网页链接进行规范化与去重，移除指向 pull request、commit 和 diff/patch 等可能暴露修改答案的链接，并将参考补丁及定位标签与模型输入严格隔离。对于 SWE-bench Multimodal，我们保留文件、模块和函数级 gold 数量均为1至15的样本；对于 OmniGIRL，我们保留仓库与提交信息有效、包含至少一项多模态或网页证据、文件级和模块级 gold 数量为1至15且函数级 gold 数量不超过15的样本。预处理后，模型仅接收问题描述、仓库与基准提交以及图像和网页证据。除非另有说明，本文所称 SWE-bench Multimodal 和 OmniGIRL 均指上述预处理后的子集。

SWE-bench Multimodal被用作主要评测集。该数据集包含92个来自5个 JavaScript/TypeScript 开源项目的软件问题，每个问题均包含至少一项图像证据。与仅提供文本描述的传统代码定位任务相比，该数据集要求定位方法联合理解问题文本、截图、页面链接和代码仓库结构，因而适合评估 MAGNET 的多模态证据理解与跨文件导航能力。我们在该数据集上完成主要对比实验、消融实验和下游补丁生成实验。

OmniGIRL  被用作跨项目和跨语言泛化评测集。该数据集包含458个软件问题，覆盖15个代码仓库，其中包括185个 Python 问题、137个 JavaScript 问题、94个 TypeScript 问题和42个 Java 问题。相较于原数据集，处理之后的数据集在项目数量、编程语言和问题类型方面具有更高的异质性，因此被用于检验 MAGNET 在更广泛软件生态中的泛化能力。
