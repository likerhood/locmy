# 一键运行与结果分析

当前版本的完整命令、50 GB 空间策略、Git 镜像回退与断点恢复见[串行评测与50GB部署](串行评测与50GB部署.md)。仓库是 `likerhood/locmy`，分支为 `rq4work`。

执行顺序为按仓库分组、逐样本完成环境对照和所有方法，再处理下一例。仓库复用；同一样本镜像复用；每次官方测试使用干净容器。`--mode evaluate` 也执行或复用环境对照，`--mode generate` 不提供官方解决率。

结果在 `runs/batches/<run-id>/`：

| 文件 | 内容 |
|---|---|
| manifest.json | 固定样本、方法、模型、输入及执行代码哈希 |
| image_pins.json | 每例固定官方镜像 digest |
| resources.jsonl | 仓库/镜像复用、回退、清理、磁盘与耗时事件 |
| records/、attempts/ | 逐例生成状态、补丁、请求/响应和应用检查 |
| evaluation/ | 官方测试与环境对照日志/报告 |
| completed_samples/ | 全部方法评测完成的样本标记 |
| paused.json | 空间、网络、测试或生成异常中止状态 |
| per_instance.csv | 逐例明细，含 unknown |
| analysis.json、analysis.md | 方法汇总与 MAGNET 对 baseline 的配对胜负 |

重新分析：

```bash
.venv/bin/python scripts/analyze_batch.py --batch-dir runs/batches/swe50-addtest3-mimo-serial-v2
```

固定分母使用本批次样本数。没有最终结论时显示 pending；resolved_percent 为 null，resolved_percent_lower_bound 仅表示当前下界。接口失败或中断不是官方未解决，保留 unknown；明确输出空补丁可记为系统未解决。Applied check 是本地补丁应用检查，不能代替官方测试。

修复 token/耗时不含历史定位成本，不自动换算美元。配对计数是描述性结果，尚未做置信区间和显著性检验。开发修复协议仍是 Agentless-inspired 独立编辑器、完整文件字节预算、每例单候选；不声称原样复现 Agentless-1.5。
