## 如何开始正式容器测试

Windows启动Docker Desktop；Settings → General 启用WSL2 engine；Settings → Resources → WSL Integration 开启当前Linux发行版，Apply。若没有WSL Integration选项，检查是否处于Windows containers模式，应切换Linux containers。操作依据：[Docker官方说明](https://docs.docker.com/desktop/features/wsl/)。

回到WSL执行：

```bash
docker version
docker info
.venv/bin/python scripts/preflight.py --env-file .env.local
```

Docker可用后仍需安装并锁定对应SWE-bench Multimodal/OmniGIRL harness，核对数据revision和镜像，先执行no-op/gold正负控，再评测生成补丁。当前没有假定任意SWE-bench版本都支持本地数据快照，因此这里不提供未经验证的“一条命令跑完整解决率”。

另外，完整比较仍缺Omni四个baseline的同模型预测，以及正式24k-token上下文打包/统一MAGNET版本。当前修复器是独立多语言开发adapter，使用字节上限并拒绝新文件；不是未修改的Agentless-1.5正式复现。
